# Terraria Auto Fishing 1.1

Отдельное приложение с русским меню для обычной Steam Terraria **1.4.5.8 (Windows, x86)**. tModLoader не нужен.

## Запуск

1. Откройте `release/TerrariaFishing.exe`. Все компоненты упакованы внутри EXE.
2. Включите **«Фоновый режим»**, затем нажмите **«Подключиться»**. Игра должна быть запущена. Если поменяли режим после подключения, подключитесь заново.
3. Войдите в мир, выберите удочку, положите наживку в инвентарь или слоты наживки. Закройте инвентарь, диалоги и карту.
4. В Terraria наведите курсор на воду и нажмите **F8**. Точка заброса сохраняется в координатах окна игры. Можно начать с уже заброшенной удочкой.
5. Теперь можно переключиться в браузер или другое приложение. В фоновом режиме заброс и подсечка выполняются внутри игры; системный курсор и активное окно не переключаются.
6. **F9** останавливает новые действия из любого окна. **F8** переключает работу. После перемещения персонажа или изменения разрешения остановите работу и снова выберите точку через F8.

Открытый интерфейс, смерть, смена удочки и внутриигровая пауза блокируют действия. При нехватке наживки, трёх неудачных забросах или не вернувшемся поплавке работа останавливается с пояснением.
Фоновый режим временно снимает именно паузу от потери фокуса; самостоятельная пауза игры продолжает учитываться. Закрытие меню отключает модуль и убирает его обработчики. Поддержка свёрнутого окна отдельно не проверялась: используйте переключение на другое окно.
Если выключить фоновый режим, остаётся режим с обычными кликами ЛКМ: тогда Terraria должна быть активным окном. Игра и приложение должны работать с одинаковыми правами доступа.

## Настройки

- **Фоновый режим** — действие удочки на игровом кадре, даже когда выбрано другое приложение. По умолчанию включён.
- **Задержка подсечки** — время после обнаружения готового улова, по умолчанию 75 мс.
- **Пауза перед забросом** — задержка после исчезновения поплавков и окончания анимации, по умолчанию 800 мс.
- **Повторный заброс** — можно отключить, оставив только автоматическую подсечку.
- **Поверх окон** — закрепляет меню над другими окнами.

«Подсечки» считает отправленные действия, а не гарантированно пойманную рыбу: игра может оборвать леску или выдать противника.
Настройки: `%LOCALAPPDATA%/TerrariaFishing/settings.json`.
Встроенные библиотеки распаковываются в `%LOCALAPPDATA%/TerrariaFishing/bridge`. При переподключении используется уже загруженный каталог собственного модуля. Файлы Terraria не меняются.

## Устройство

Основное приложение через ClrMD определяет расположение полей в памяти и затем читает их через ReadProcessMemory. Учитываются выбранный предмет, наживка и только собственные активные поплавки.
Условие подсечки сверено с локально установленной 1.4.5.8: `ai[0] == 0`, `ai[1] < 0`, `localAI[1] != 0`.

В фоновом режиме небольшой модуль .NET Framework подключается через EasyHook к основному AppDomain игры. Harmony добавляет обработчики к `Player.ItemCheck` и `FocusHelper.UpdateFocus`. Действия выполняются на игровом потоке, с повторной проверкой персонажа, удочки, интерфейсов и поклёвки; старые команды отбрасываются. Координаты прицеливания и поля ввода восстанавливаются после вызова игрового обработчика. Глобальный SendInput в этом режиме не используется.
Канал связи — локальный именованный канал со случайным именем. Без heartbeat активные действия и снятие паузы от потери фокуса прекращаются через 3 секунды; при разрыве соединения обработчики удаляются. После отключения загруженные сборки могут оставаться в памяти до закрытия игры, без активной автоматизации.

В обычном режиме внедрения нет: используются чтение памяти и SendInput с проверкой активного окна.
Подтверждена совместимость с **1.4.5.8**; фоновый модуль отказывает в подключении к другой версии.

## Сборка и проверки

Нужны .NET SDK 9 и доступ к NuGet. Для игры уже установлен .NET Framework 4.x; приложение использует .NET Framework 4.8 для загрузчика. Основной EXE содержит собственный .NET 9.

```powershell
dotnet run --project tests/LogicTests.csproj
./build.ps1
```

Сначала собирается загрузчик, затем `build.ps1` упаковывает его и библиотеки в ресурсы EXE. Если изменяется код модуля, уже загруженного в игру, для разработки используйте новую версию сборки или перезапустите Terraria.

- `--diagnose` — один снимок состояния в `diagnostic.txt` без действий. Файл может содержать имя персонажа.
- `--probe-background` — проверяет подключение, ARM/STOP, обработку команды с заведомо недопустимыми координатами и отключение. Заброс и подсечка не выполняются; мир может кратковременно продолжать симуляцию во время проверки.
- `--render-ui` — создаёт `menu-preview.png` с интерфейсом.

Пройдена 31 проверка логики, включая работу без фокуса и сохранение блокировок. Проверены подключение модуля к живой Terraria, обмен командами, обработка защитной команды на игровом кадре и отключение. Полный цикл ловли на реальном водоёме ещё не проверялся.

Исходники: `src/`, `bridge/`, `injector/`. Тесты: `tests/`. `tools/` — утилита анализа локального EXE игры. Игровой IL не распространяется с исходниками.
Сторонние библиотеки: Microsoft ClrMD, EasyHook, Harmony; лицензии EasyHook и Harmony находятся в `THIRD_PARTY_NOTICES.txt`.
